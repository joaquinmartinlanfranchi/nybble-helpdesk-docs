Nybble AI Help Desk · Operator Guide

Quick Guide · Operator agent

How to clear the escalation queue: take a case, decide what applies, and leave everything on record so your metrics reflect your work. Meant to be kept open while you work the queue, not read start to finish before you begin.

The first thing to know All enabled agents share a single pool of tickets — there is no automatic assignment or routing by specialty. You only see escalations for the customers assigned to you, sorted by priority CRITICAL > HIGH > MEDIUM > LOW, and whoever clicks first wins the case.

Step by Step

Step 1 · Take a Case agent
  1. Open the Escalation Queue — you'll only see the customers assigned to you.
  2. Pick a case and click Take Case.
  3. The first click wins: if another agent took it before you, you'll see "Taken by <name>" and the button updates on its own.
  4. The case moves to In Review.
Step 2 · Read the Context agent
  1. Open the detail view — today it appears below the list, so you may need to scroll.
  2. Read the user's literal query and the AI-generated summary.
  3. Check priority, category, module, customer, and contact.
Step 3 · Choose the Action agent
  • Resolved — you resolved it yourself directly, with no external ticket.
  • Reject — no action applies (bot hallucination, or the topic doesn't belong here).
  • Return — you need something from the user to continue. It's the only CTA with a text box (no attachments).
  • Approve and Create in Jira — you can't resolve it yourself, it gets escalated to Jira.

All four actions will ask you for the resolution time (hours and minutes) — it's always required.

Step 4 · If You Need to Talk to the User agent
  1. There is no agent ↔ user chat inside the platform. This is a deliberate decision, out of scope for V1.
  2. Contact them via Slack or email, outside the desk.
  3. If all you need is a specific answer from them, use Return to keep the reason on record.
Step 5 · Close the Case agent
  • Enter the resolution time — it's the only input behind all time KPIs, there's no automatic measurement.
  • Resolved adds 1 to your "resolved by me" counter in My Performance.
  • If you returned the case and the user has already answered you (via Slack or email), go back to the incident and manually change it from Returned to In Review — that step is not automatic.

Things to Keep in Mind

Known Issues During the Pilot
  • There's no agent↔user chat inside the platform — this is a deliberate decision, not a bug, but it shapes your entire workflow. LABS-516 LABS-547
  • You can't attach anything when returning or resolving a case — there's no way to leave evidence inside the desk. LABS-516
  • If you reject a case, the user does not receive an automatic notification — communicating the reason is your responsibility.

Quick Checklist

Do This
  • Always enter the resolution time, in hours and minutes
  • Communicate via Slack or email and keep a record of what you discussed
Avoid This
  • Assuming the user sees your explanation inside the platform
  • Rejecting without telling the user the reason through another channel
