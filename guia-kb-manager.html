Guía rápida · KB Manager kb

Cómo cargar y mantener la Base de Conocimiento que usa el bot para responder. Pensada para tener abierta en una pestaña mientras trabajás en la plataforma en la otra — no hace falta leerla de punta a punta antes de empezar.

Por qué importa lo que subís acá El bot solo responde con lo que encuentra en la Base de Conocimiento — nunca inventa una respuesta ni completa con conocimiento general. Si un documento no está cargado, o está desactualizado, esa consulta va a terminar escalada a un operador humano. Documentación clara y vigente es lo que hace que la mesa sea asertiva.

Paso a paso

Paso 1 · Entrar a la Base de Conocimiento kb
  1. Iniciá sesión con tu usuario de KB Manager.
  2. En el menú, entrá a la sección Base de conocimiento.
  3. Ahí vas a ver la lista de todo lo ya cargado, con su estado de indexación por documento.

Si no te aparece esta sección en el menú, tu usuario no tiene el rol de KB Manager asignado — pedile al Admin del tenant que te lo habilite.

Paso 2 · Subir un documento kb
  1. Desde la Base de conocimiento, buscá la opción para subir un documento nuevo y seleccioná el archivo.
  2. Formato recomendado: .doc / .docx. Evitá PDF por ahora — hay un bug conocido en la carga (ver "Antes de subir" más abajo).
  3. La carga es de un documento a la vez. Repetí el paso para cada archivo.
  4. Después de subir, la mesa dispara sola la indexación — no hace falta ninguna acción adicional de tu parte.
Paso 3 · Definir el alcance kb
  1. Al subir, podés asignar el documento a una o varias compañías del tenant.
  2. Si no asignás ninguna, el documento queda tenant-wide: disponible para todas las compañías del tenant.
  3. Si le asignás una o más compañías, el bot solo lo va a usar para responder consultas de esas compañías puntuales.

Usalo para separar contenido que no debería cruzarse entre clientes o áreas — por ejemplo, políticas internas de una compañía específica.

Paso 4 · Confirmar que indexó bien kb
  1. Cada documento pasa por: Pendiente → Indexando → Listo (o Error).
  2. Un documento recién subido no está disponible para el bot hasta que llega a "Listo".
  3. Si queda en Error: no se va a usar para responder. Revisá el formato del archivo y volvé a intentar la carga.

El resumen de temas de la KB (lo que ve el bot para saber qué está fuera de alcance) se regenera solo cada vez que subís, sincronizás o cambia el estado de un documento — no tenés que hacer nada manual para eso.

Paso 5 · Mantenerla al día kb
  • Contenido claro y vigente: el bot responde literalmente con lo que hay ahí adentro, así que un documento ambiguo produce una respuesta ambigua.
  • Evitá contenido contradictorio entre dos documentos sobre el mismo tema — el bot no tiene forma de elegir cuál es el correcto.
  • ¿Cambió una política o un proceso? Volvé a subir la versión actualizada; no hay edición inline del contenido ya cargado.
  • Revisá de tanto en tanto que no queden documentos en estado Error sin resolver.
Paso 1 de 5

Antes de subir, tené esto en cuenta

Problemas conocidos durante el piloto
  • La carga de PDF falla con el error matrix is not defined. Usá .doc / .docx mientras este bug esté abierto. LABS-573
  • Una vez subido, no se puede reabrir ni leer un documento desde la plataforma para revisar su contenido — guardá una copia de lo que subís en otro lado como referencia. LABS-558
  • Cargar la KB desde fuentes externas (Google Drive) todavía no está definido para el piloto. LABS-576

Chequeo rápido

Hacé esto
  • Subí en .doc / .docx
  • Un documento por tema, sin contradicciones entre archivos
  • Verificá que el documento llegó a estado Listo
  • Guardá una copia propia de cada archivo que subís
Evitá esto
  • Subir en PDF (falla la carga)
  • Dar por cargado un documento que quedó en Error
  • Esperar poder reabrir un documento ya subido desde la plataforma
